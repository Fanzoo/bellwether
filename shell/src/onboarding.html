Set up Bellwether

An earlier Bellwether is on this Mac

Moving it into the app from this window comes with a later version. Until then, this window won't turn on start at login or install hooks, because the two would fight over one port. Everything else here works.

Start at login

Bellwether has two parts: a small background brain that Claude Code's hooks talk to, and the strip of sheep. Starting both at login (recommended) means the hooks always find a brain to talk to.

    Hooks

    Claude Code tells Bellwether what each session is doing through hooks in your settings file. Below is exactly what installing changes in it; nothing is written until you choose Install. Other tools' hooks are left exactly as they are, and a backup of the file is kept.

    Start at login is off. Hooks still work while Bellwether is running, but whenever it isn't, every Claude Code session prints a hook error on each prompt and tool call. 

      
          
      
            
          
      
        
      
        
      
      
      

      
      
        
      Optional: sheep on the Dock
      
        
      
          With the Accessibility permission, sheep stand on the Dock's top edge, within its
          width. Without it they walk the full width of the screen just above the Dock.
          Bellwether only reads where the Dock is; it never clicks or types for you.
        
      
        
      
        
      
          
        
      
        
      
      
      

      
      
        
      Optional: click a sheep to jump to its tab
      
        
      
          Clicking a sheep brings its session's terminal forward. In iTerm2 and Terminal it can
          also pick the exact tab, which needs the Automation permission for that app.
          Bellwether asks the app how many windows it has, once, so that macOS asks you.
          Refusing is fine: a click still brings the app forward.

          Optional: the bellwether command
          
        
          
          For a terminal: bellwether status, bellwether doctor and the
          rest. This makes a link at ~/.local/bin/bellwether; no administrator
          password is needed.
